## 개요 및 개발동기

###  프로젝트 개요
> 최신 **뉴스를 카테고리별로 분류·요약**하여 사용자에게 제공하고, 관심사 분석을 기반으로 **맞춤형 기사를 추천**하는 뉴스 요약 서비스입니다.
> 댓글, 추천, 공유, 북마크 등 **커뮤니티 기능을 통해 사용자 간 소통을 강화**하며, **키워드 검색**으로 원하는 기사를 쉽게 찾을 수 있습니다.
> 또한 이동 중에도 편리하게 뉴스를 접할 수 있도록 TTS 음성 서비스를 제공해 뉴스 소비의 **접근성과 효율성**을 높였습니다.

- **Spring** 기반 서버, **React** 프론트엔드, **OracleDB**를 이용한 실시간 데이터 처리 및 저장

###  개발 동기
- 요즘 숏폼 콘텐츠의 확산으로 긴 동영상이나 긴 기사보다 짧고 핵심적인 콘텐츠를 선호하는 경향이 커지고 있습니다. 이에 따라 뉴스 기사를 요약해 보다 쉽고 빠르게 확인할 수 있는 서비스의 필요성을 느꼈습니다. 긴 뉴스 기사를 핵심만 담아 제공한다면 출퇴근길이나 등하굣길처럼 짧은 시간에도 화제의 뉴스를 효율적으로 접할 수 있을 것이라 판단하여 ‘ShortNews’ 서비스를 기획하게 되었습니다.

### 기대 효과
- 짧은 시간안에 뉴스 기사를 보거나 들을 수 있기 때문에 직장인, 학생들이 접하기 쉽습니다.
- 사용자가 선호하는 카테고리만을 볼 수 있어서 원하는 기사만 볼 수 있습니다.
- 사용자가 선호할 만한 기사를 추천해줌으로써 새로운 기사를 볼 수 있습니다.

## 주요 기능

### 기사 수집
- 네이버 뉴스 정치, 경제, 사회, 생활/문화, 세계, IT/과학, 연예, 스포츠 카테고리에서 최신 뉴스 크롤링
- 이전에 수집된 기사, 내용이 적은 기사, 사진/영상/인터뷰 기사 제거
- 군집화에 영향을 줄만한 특수문자 및 단어 제거

### 군집화
- 현재 이슈되는 뉴스를 선별하기 위해 카테고리 내에서 유사한 기사끼리 군집 생성
- 형태소 분석기를 사용하여 제목과 본문에서 명사 추출
- AI 비지도 학습을 사용하여 밀도 기반으로 군집화
- 카테고리 별로 밀도가 높은 상위 군집 10개를 추출

### 기사요약
- 같은 군집 내 여러 유사한 기사들을 하나의 기사로 요약
- 문장 간 유사도가 높은 문장은 하나만 남기고 제거 

### 사용자 맞춤 추천
- 사용자 별로 선택한 카테고리와 기사 조회 로그를 바탕으로 사용자간 유사도 계산
- 사용자와 유사도가 높은 다른 사용자들이 읽은 기사를 정리하여 점수 부여
- 가장 높은 추천 점수를 가진 기사들을 선별하여 사용자에게 제공

### 키워드 추출
- 요약된 기사들에서 고유 명사를 추출하여 출현 빈도 계산
- 각 카테고리 별로 키워드들을 분류하고, 출현하는 기사 수와 한 기사 내에서의 출현 빈도에 따라 점수 부여
- 각 카테고리 별로 가장 높은 점수를 가진 키워드를 정리하여 사용자에게 제공

## 느낀 점

- 협업을 통해 개개인의 역량도 중요하지만 **소통의 중요성**을 체감
- 프로젝트 기획, DB 설계, API 구성, 보안 설정, 오류 디버깅 등 많은 **학습과 경험**의 기회 
- **데이터를 수집하고 의미있는 정보를 도출하는 과정을 경험**하는 계기
